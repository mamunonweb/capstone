\begin{center}
    \section*{\textbf{Abstract}}
\end{center}
Early and reliable diagnosis of potato leaf diseases is critical for smallholder food security and reducing unnecessary agrochemical usage. While modern Deep Learning (DL) architectures achieve strong accuracy on agricultural imagery, many high-performing ensembles are too large for economical edge or web deployment and operate as opaque ``black boxes'' that offer farmers little visual justification or actionable field guidance. This thesis develops an accurate, compact, and explainable potato leaf disease detection and intelligent advisory system built around a lightweight fine-tuned MobileNetV2 classifier (2,264,389 parameters, 8.64~MB) and deployed as a bilingual (English and Bengali) web application for farmers.

Using a curated 5-class uncontrolled field dataset of 2,321 potato leaf photographs (Bacteria, Fungi, Healthy, Phytopthora, and Virus), near-duplicate images are grouped via perceptual difference hashing ($\text{dHash} \le 10$, yielding 2,283 distinct groups) prior to an 80:10:10 leak-aware \texttt{StratifiedGroupKFold} split (1,859 training, 231 validation, and 231 unseen test images). The proposed model is trained on dual NVIDIA Tesla T4 GPUs with capped inverse-frequency class weighting, leaf-realistic geometric and photometric augmentation, and a two-stage AdamW fine-tuning strategy that restores the best frozen-head checkpoint before unfreezing the top 54 backbone layers while keeping all Batch Normalization layers frozen to prevent fine-tuning distribution shock.

Under this identical leak-aware evaluation protocol, the proposed 8.64~MB MobileNetV2 model achieves \textbf{93.51\%} single-pass test accuracy, \textbf{0.9272} macro-F1, and \textbf{0.4466} test loss (improving further to \textbf{93.94\%} accuracy and \textbf{0.9317} macro-F1 with zero-parameter 4-view Test-Time Augmentation), with verified export integrity ($0.00 \times 10^{0}$ maximum probability discrepancy). In direct benchmarking against four heavier or alternative architectures on the exact same test split, it strictly dominates the accuracy-to-size Pareto frontier---surpassing the 13.7$\times$ larger MultiNet-V3 ensemble (EfficientNetB0 + MobileNetV2 + ResNet50, 31.08M parameters, 118.55~MB, 90.91\% accuracy, 0.8975 macro-F1), Benchmark MobileNetV2 (9.87~MB, 86.15\%, 0.8486 macro-F1), InceptionV3 (85.18~MB, 84.42\%, 0.8296 macro-F1), and NASNetMobile (17.33~MB, 72.73\%, 0.7049 macro-F1). Gradient-weighted Class Activation Mapping (Grad-CAM) confirms lesion-grounded visual explanations from the final convolutional layer (\texttt{Conv\_1}), and a safety-constrained Google Gemini advisory module translates predictions into practical farmer guidance inside a live FastAPI and React web application supporting camera capture, batch analysis, PDF/CSV export, and interactive bilingual chat.
